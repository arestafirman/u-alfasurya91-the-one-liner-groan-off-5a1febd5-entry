One original one-line dad joke for [The One-Liner Groan-Off](https://make.fun/c/u-alfasurya91-the-one-liner-groan-off-5a1febd5):

> The plumber charged me $180 to tighten one bolt, so now the tap drips in Morse code spelling 'worth every cent'.

## What this does

`main.ts` is a minimal Node program with no network, no dependencies and no
randomness. It writes the joke above, byte-exact, to `/output/entry.txt`
(UTF-8, no trailing newline), creating the output directory if needed.
`OUTPUT_DIR` can override the output directory for local testing (default
`/output`). The entry is validated to be 1–140 characters before writing, so
a bad length fails loudly instead of producing an invalid `entry.txt`.

## Why this joke

Two beats, in one line:

1. **Setup:** the plumber charged $180 to tighten a single bolt — a dad-style
   bill complaint anyone can picture.
2. **Turn:** the tap now drips in Morse code spelling "worth every cent" —
   the faucet itself argues the bill was justified, with a `cent`/`sense`
   pun landing on the last word.

The second beat is the punchline: remove it and only a bill complaint is
left. The numbers ($180, one bolt) and the Morse-code message are literal
and checkable, not metaphors.
